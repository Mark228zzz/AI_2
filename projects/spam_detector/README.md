# Spam detector

This project is a Ham/Spam classifier designed to determine rather email is spam or ham(not spam). The Kaggle dataset that I used contain 5,574 example of emails. Approximately 87% of ham and 13% of spam emails.

## **Install Kaggle dataset**
You will need to download the Kaggle dataset. Just run this file `download_dataset.py` it will download Kaggle dataset into you ~/.cache/kagglehub/... And after that you can run `main.py` it will automatically find the path to the Kaggle dataset.
